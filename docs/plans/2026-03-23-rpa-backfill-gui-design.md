# 本地 GUI 集成历史发送状态回填

## 目标
- 在本地 GUI 中提供一个“补历史发送状态”按钮。
- 点击后执行 `tools/backfill_rpa_send_state.py`。
- 回填完成后，把摘要写到状态栏和日志，并自动刷新待发送任务统计。

## 设计
- 按钮位置：
  - `第 1 步：选择任务文件`
  - 与 `↻ 刷新发送任务` 同一行
- 交互：
  - 点击后先弹确认框
  - 确认后后台执行回填脚本
  - 成功时显示：
    - `已补历史：匹配 X，未匹配 Y，歧义 Z`
  - 失败时弹错误框
- 安全边界：
  - 仅补可安全匹配的历史记录
  - 不修改当前任务 CSV
  - 不自动开始发送

## 测试
- 为 GUI 辅助函数补单测：
  - 回填命令拼接正确
  - 回填摘要解析正确
  - 状态文本包含匹配/未匹配信息
